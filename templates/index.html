リアルタイム変換モード

マイク入力をブラウザ内で即時処理します。Flaskは画面配信だけを担当するため、低遅延です。

STOP
入力レベル
入力RMS: -

ヘッドホン推奨です。音が出ない場合は「テスト音」→「リアルタイム開始」→入力レベル確認の順に切り分けます。localhostまたはHTTPSで動作します。

アップロード変換モード

または、下のファイル選択からWAV/FLAC/OGG/AIFFを指定します。

音色パラメータ

おすすめ設定

古いボコーダー風

base_freq=110 / bands=12〜16 / tone=Saw / dry_mix=0.02

強めロボ声

base_freq=100 / bands=10〜14 / tone=Square / dry_mix=0.00

聞き取りやすさ優先

base_freq=130 / bands=20〜24 / tone=Saw / dry_mix=0.05

リアルタイム変換はブラウザ内処理です。サーバーへ音声を送らないので軽い反面、録音保存はしません。 保存したい場合はアップロード変換モードを使ってください。
