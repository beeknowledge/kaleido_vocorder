# Retro Vocoder Voice Changer - Flask Sample

Python + Flask の簡易ボコーダー風ボイスチェンジャーです。

この版では次の2モードを入れています。

1. アップロード変換モード
   - WAV / FLAC / OGG / AIFF をアップロード
   - Python / SciPy 側でチャンネル・ボコーダー風に変換
   - WAVで保存・再生

2. リアルタイム変換モード
   - ブラウザのマイク入力を使用
   - Web Audio APIでリアルタイム変換
   - Flaskサーバーへ音声を送らず、ブラウザ内で処理

## 起動方法

```bash
cd ymo_vocoder_flask_sample
./run.sh
```

または手動で起動します。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

ブラウザで開きます。

```text
http://127.0.0.1:5000
```

## リアルタイム変換モードの注意

リアルタイム変換はブラウザのマイクを使います。

- `localhost` または `HTTPS` で動作します
- スピーカー出力だとハウリングしやすいので、ヘッドホン推奨です
- Chrome / Edge 系ブラウザ推奨です
- Firefoxでも概ね動きますが、音の出方が少し変わることがあります
- スマホでは端末やブラウザによって遅延が大きくなる場合があります

## おすすめ設定

### 古いボコーダー風

- 基準音程: 100〜120 Hz
- バンド数: 12〜16
- 波形: Saw
- 原音ミックス: 0.00〜0.03

### 強いロボ声

- 基準音程: 90〜110 Hz
- バンド数: 10〜14
- 波形: Square
- 原音ミックス: 0.00〜0.02

### 聞き取りやすさ優先

- 基準音程: 120〜150 Hz
- バンド数: 18〜24
- 波形: Saw
- 原音ミックス: 0.04〜0.08

## MP3を使いたい場合

このサンプルは安定性重視でMP3を直接対象にしていません。
ffmpegでWAVに変換してください。

```bash
ffmpeg -i input.mp3 -ar 44100 -ac 1 input.wav
```

## 技術メモ

アップロード変換モードは、音声を複数の周波数帯域へ分割し、各帯域の包絡を取り出してシンセ波側へ掛け合わせます。
リアルタイム変換モードは、Web Audio API の BiquadFilter / WaveShaper / GainNode / OscillatorNode を組み合わせた簡易チャンネル・ボコーダーです。

本格的にするなら次の拡張が有効です。

- AudioWorklet化してより細かいDSP制御を行う
- MIDIキーボード入力でキャリア音程を制御する
- WebRTCで遠隔配信に乗せる
- ノイズキャリアを追加して子音を強調する
- プリセット保存機能を追加する

## リアルタイム音声が出ない場合

この修正版では、リアルタイム変換モードに以下を追加しています。

- テスト音ボタン
- 入力レベルRMS表示
- ボコーダー感度スライダー
- 入力モニタースライダー
- AudioContext resume処理

切り分け順は以下です。

1. 「テスト音」を押す  
   - 聞こえない場合は、ブラウザ/OS/スピーカー/出力デバイス側の問題です。
2. 「リアルタイム開始」を押す  
   - マイク許可を承認してください。
3. 入力レベルが動くか確認  
   - 動かない場合は、マイク権限または入力デバイスの問題です。
4. 入力モニターを 0.20〜0.40 に上げる  
   - 自分の声が聞こえればマイク経路は正常です。
5. ボコーダー感度を 30〜60 に上げる  
   - ロボ声が出ます。歪む場合は下げてください。

注意: スピーカーで使うとハウリングします。ヘッドホン推奨です。
